# P02-010.1 — Dynamic Top 20 Prediction Intelligence

Adds the missing product layer: **what are markets actually predicting?**

## Product behavior
- Builds a dynamic Top 20 from live Polymarket + Kalshi observations.
- Classifies markets into Technology, Equities, Crypto, Energy, Precious Metals, Life & Society, Politics, Sports, or Other.
- Shows the actual market question, market-implied probability, venue, activity/volume and deterministic trending score.
- Adds category filters to the P02 dashboard.
- Moves raw venue record counts to Data Coverage / System Status.
- Keeps cross-market matching/discrepancy logic unchanged.
- Keeps execution disabled.

## Ranking
`DETERMINISTIC_RELEVANCE_V1` uses available volume/activity, liquidity, freshness, data quality, usable probability, and topic classification. A diversity cap prevents one category from occupying the entire first pass of the Top 20; remaining slots are then filled by score.

This is a **P02 curated intelligence ranking**, not an official Polymarket/Kalshi ranking and not a forecast.

## Refresh
The `P02 Dynamic Prediction Intelligence` workflow runs every six hours and can also be started manually. It refreshes a wider source pool, rebuilds the Top 20, republishes the dashboard, and commits generated data.

## Acceptance
Expected workflow output includes:

`P02-010.1 DYNAMIC TOP 20: PASS`
