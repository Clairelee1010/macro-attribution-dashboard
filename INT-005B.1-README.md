# INT-005B.1 · Verified Tokenization Intelligence

## Scope
- Upgrade official-source-backed mappings to VERIFIED.
- Add Tokenized Product, Provider, Structure, Chain, Evidence URL, and Last Verified.
- Keep thematic gold mapping explicitly separate from tokenized ETF shares.
- Add fixed-height scroll containers and sticky headers for large tables.

## Verified source policy
Only official provider documentation/announcements are used for VERIFIED status in this release.

## Current verified examples
- Ondo Stocks: AAPLon, MSFTon, NVDAon, AMZNon, GOOGLon, METAon, TSLAon, SPYon, QQQon, IVVon, IWMon.
- Paxos PAXG: thematic physical-gold mapping for GLD/IAU context only; PAXG is not a tokenized share of GLD or IAU.

## Guardrail
VERIFIED means the mapping/product claim is supported by an official source as of the stated verification date. It is not an investment recommendation and does not imply identical legal/shareholder rights across products.
